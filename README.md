Here it was my first time dealing with pretty big datasets, and learning how to sanitize them and treat them in general.
Tbh at first it was a constant headache because I was running out of RAM and the program would just crash, but then I realised with my team that the key was not only dividing the dataset in chunks but releasing the memory used for each one of them when it was not needed, and saving the selected features of the dataset in a file instead of my RAM.
Of course, our optimizing methods improved over the lessons, and I think I could come up with better techniques in the future.
